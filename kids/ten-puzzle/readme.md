# 🔟 テンパズル（Ten Puzzle）

4つの数字と ＋ − × ÷ ・括弧をつかって **10** をつくるブラウザゲームです。
iOS アプリ「MAKE10」収録のテンパズルを移植したものです。

## 🎮 ゲーム概要

4枚の数字タイルを**すべて1回ずつ**使って、計算結果が 10 になる式を組み立てます。

3つのモードがあります。

| モード | 出題範囲 | 問題数 |
| --- | --- | --- |
| ⭐️ Normal | ＋ − だけで10を作れる問題 | 175問 |
| ⭐️⭐️ Hard | 10を作れる問題すべて | 552問 |
| ⭐️⭐️⭐️ Challenge | ＋ − だけでは作れない問題＋10を作れない問題 | 377問＋163問 |

画面に出すモード名は Normal / Hard / Challenge の3段階です。
問題データ側の難易度コード（easy / normal / hard / impossible）とは別物です。
各モードの範囲は `game.js` の `MODES` が、問題データから読み込み時に絞り込みます。

「＋ − だけで作れるか」は、4つの数字を＋側と−側に分けて差が10になるかで
判定しています（`canMakeWithPlusMinus()`）。括弧を使っても符号の組み合わせに
直せるためです。単項マイナスは使えないので、＋側が空の分け方は除きます。

Challenge モードには「そもそも10を作れない問題」が混ざります。
10問ごとに2〜4問の割合です。見破って「Can't make 10!」を押せば正解です。
このボタンは Challenge モードでだけ表示されます。

外すと**クリアタイムに1分（`IMPOSSIBLE_MISS_PENALTY_SEC`）足されます**。
足すのは1問につき1回だけです（誤タップやダブルタップで倍にしないため。
防ぎたい攻略法は1問に1回押せば成立するので、1回に絞っても抑止力は変わりません）。
代償が無いと「まず押して、作れると分かってから解を探す」のが最適手になり、
Challenge の山場（解が無いと確信するまで探す判断）が丸ごと消えて、
クリアタイムが Hard の速さの記録になってしまうためです。
タイムにだけ効くので、記録を狙わない場合は何も起きません。
スコアも減らず、問題も進みません。

こたえあわせの不正解に代償は付けません。式が10にならないのは作りかけの試行で、
途中の計算結果は式の下にすでに出ています。いっぽう「作れない！」は結論の宣言です。

### スコアと出題数

- スコアは**ヒントを使わずに続けて正解した数**です
- ヒントを使うと、その時点でカウントが止まります（その問題も加点されません）
- まちがえても（10にならない式でこたえあわせしても）カウントは止まりません
- ヒントを使っても**10問目までは必ず遊べます**（`MIN_QUESTIONS`）
- 10問目の時点でまだヒントを使っていなければ、**20問目まで続きます**（`MAX_QUESTIONS`）

以前は上限が無く、ヒントを使わなければいつまでも出題が続きました。
Normal は「＋側と−側に振り分けて差が10になる組を探す」とコツが分かると
ほぼ全問解けてしまうため、記録が実力ではなく根気の記録になっていました。
上限を置くと20点が満点になり、Normal を取り切ったら Hard へ、という
3モードの階段がはじめて機能します。

### 進行表示の分母

ヘッダーの「n / 20」の分母は、その時点で遊べる問題数をそのまま出します
（`renderProgress()`）。

| 状態 | 分母 |
| --- | --- |
| ノーヒントで続いている | 20（`MAX_QUESTIONS`） |
| ヒントを使った・10問目まで | 10（`MIN_QUESTIONS`） |
| ヒントを使った・10問目より先 | 今の問題番号（その問題が最後） |

分母を20に固定すると、11問目で「11 / 20」と出した直後にヒントを使った人が
その問題で終わってしまい、打ち切られたように見えます。ヒントで連続が止まった
時点で `renderProgress()` を呼び直すので、分母はその場で正しくなります。

### クリアとクリアタイム

**20問すべてをヒントなしで正解すると「クリア」です。**

ヒントを使うと10問目で終わるので、20問目に到達した時点でノーヒントは
確定しています。不正解では問題が進まないので、あきらめずに粘れば必ず満点に
なります。満点は「才能」ではなく「ヒントを使わずに20問ぶんねばった」証明です。

クリアしたときだけ所要タイムを記録します。満点は必ず20点で、人による差が
数字に出ないため、記録をタイムに切り替えています。

- リザルトは「連続正解 20」ではなく「クリアタイム 2:14」の表示になります
- モード選択の記録も `★ 17` から `🏆 2:14` に変わります
- 一度クリアしたモードでは、満点を逃した回のリザルトにもベストタイムを出します
  （更新すべき記録がもうタイムだけなので）
- **プレイ中は時間を見せません。** 画面に時計があると、計測のつもりでも
  制限時間と同じ焦りを生みます。1問ごとの制限も、全体の制限もありません

保存キーはモードごとに分かれています。

| キー | 中身 |
| --- | --- |
| `tenpuzzle_hi_A` / `_B` / `_C` | 連続正解のベスト（クリア前のモードだけ表示） |
| `tenpuzzle_time_A` / `_B` / `_C` | クリアタイムのベスト（秒。あればこちらを表示） |

旧版は上限が無かったため、20を超える連続正解の記録が残っている環境があります。
その記録はクリアすれば表示から外れます（保存値は残りますが二度と読みません）。
20を超える記録を持っている人は20問満点を確実に取れる層なので、
移行処理もクリップ処理も入れていません。

### 途中の計算結果

式の下に、組み立て途中の計算結果を「= 7」のように表示します。
末尾の記号や開き括弧は書きかけとして外し、閉じていない括弧は補って計算します
（`(3 + 4 ×` → `= 7`）。割り切れないときは `1/3` のように分数で出します。
10になると緑色で表示します。

## 🕹 操作方法

**PC（キーボード・テンキー）**
- クリック：数字・記号を式に入れる
- `1` `2` `3`：トップ画面でモードを選ぶ
- 数字キー / `+` `-` `*` `x` `/` `(` `)`：同じ入力ができる（テンキーも可）
- `Enter` / `=`：こたえあわせ
- `Backspace`：ひとつ戻す
- `Esc` / `Delete`：式をぜんぶ消す
- `H`：ヒント
- `N`：作れない！（Challenge のみ）
- リザルト画面：`Enter` でもう一度、`Esc` でモード選択へ

押しっぱなしの連打、Ctrl / ⌘ / Alt 付きのキー、日本語入力の変換中のキーは無視します。
トップ画面のキー操作の説明は、タッチ端末では表示しません。

**スマホ / タブレット**
- タップ：数字・記号を式に入れる

## 🧩 特徴

- 何度でも式を作り直せます。**制限時間はありません**
  （クリアタイムは計測しますが、時間で打ち切ることはしません）
- 💡 Hint で解の例を表示できます（使うと連続正解のカウントが止まります）
- ベスト記録はブラウザ内（localStorage）にのみ保存されます

## 🌐 表示言語

英語をメイン、日本語をサブとする方針でサイト内の他ゲームと揃えています。

- `html` は `lang="en"`。日本語の行には個別に `lang="ja"` を付与
- 日本語の従行は `.tip-ja`（`font-size: 0.9em`）で一段小さく表示
- `game.js` が出す判定メッセージは `Correct! / 正解！` のように英日併記
- 基本は英語表記で、必要な部分だけ日本語を併記します。
  あそびかた（ルール・スコア・キー操作）とモードの説明文は日本語も併記しています

## 🧱 技術仕様

**外部リクエストはゼロです。**
フォントは `/fonts/` の Nunito を自己ホストし、問題データは `game.js` に
定数として直接埋め込んでいます。fetch も XHR も使っていないため、
オフラインでも動作します。

### 問題データ

MAKE10 アプリの `ten_puzzle_problems.json`（全715問）から生成しました。
アプリとまったく同じ問題・同じ難易度が出ます。

1問の形式は `[数字4桁, 解の個数, 難易度コード, 解の例]` です。
オブジェクト形式のままだとキー名が715回くり返されてファイルが5倍以上に
膨らむため、配列に圧縮して約18KBに収めています。

難易度コード： `e` = easy（403問） / `n` = normal（102問） /
`h` = hard（47問） / `x` = impossible（163問）

問題を作り直したいときは、MAKE10 リポジトリの
`Scripts/ten_puzzle_solver.py` で再生成できます。

### 判定ロジック

アプリ側の `TenPuzzleModels.swift` と同じ手順です。

1. 4つの数字を全部使っているか
2. 式として文法的に正しいか（再帰下降パーサーで解析）
3. 計算結果が 10 か（誤差 `1e-9` まで許容）

3 でぴったり 10 かを見ずに誤差を許すのは ÷ があるためです。
`1÷3×3` は浮動小数点では `0.9999999999999998` になり、
厳密比較では正しい式が不正解になってしまいます。

**検証済み：** 収録されている解の例552件すべてが、このパーサーで
10 と判定されることを確認しています。

## 🔧 サイトへの組み込み（完了済み）

このゲームは組み込み済みです。以前ここには TOP ページへカードを
追加する手順が書いてありましたが、2026-11-01 の構成変更で内容が
合わなくなったため差し替えました。

現在の構成はこうなっています。

- こども向けコンテンツは `/kids/` 配下に集約されている
- TOP ページにゲームごとのカードは無く、`/kids/` への入口カードが1枚あるだけ
- ゲームの一覧はハブ（`/kids/index.html`）が持っている
- `_headers` の `/kids*` ブロックが、この配下すべてに厳格な CSP を当てている
- `_redirects` が旧URL（`/ten-puzzle/`）を新URLへ 301 転送している

したがって、新しいゲームを足すときに触るのは TOP ではなく
**ハブと sitemap.xml** です。TOP 側の編集は不要です。

⚠️ `/kids/` 配下には外部リンクを置きません（App Store・SNS を含む）。
   こどもが外部サイトへ出られないようにするための方針です。


```
| `ten-puzzle/`        | ブラウザゲーム：テンパズル（四則演算で10をつくる） |
```
